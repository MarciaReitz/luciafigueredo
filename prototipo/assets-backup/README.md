## 🔄 Como Usar

Para adicionar uma destas imagens à LP:

1. Copie de `assets-backup/` para `assets/`
2. Atualize a referência no `index.html`
3. Teste no navegador
4. Faça commit: `git add -A && git commit -m "Update: troque foto de [seção]"`
